# ศูนย์รวมลิงก์รายงานงาน ป. — ตำรวจภูธรจังหวัดปราจีนบุรี

เว็บรวมทางลัดรายงาน 6 รายการ แบ่งตามกำหนดเวลา 08.00 น. และ 09.00 น. ใช้ได้บนโทรศัพท์และคอมพิวเตอร์ ไม่ต้องติดตั้ง ไม่ต้องใช้ฐานข้อมูล

## เปิดใช้งาน

- เปิดไฟล์ `index.html` ในเบราว์เซอร์เพื่อลองใช้งาน
- หรืออัปโหลดไฟล์ `index.html` ไปไว้ที่ระดับบนสุด (root) ของ GitHub Repository
- ไปที่ GitHub Repository → **Settings** → **Pages** → **Build and deployment** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → **Save**
- รอให้ GitHub Pages แสดง URL เว็บไซต์ โดยปกติจะเป็น `https://ชื่อผู้ใช้.github.io/ชื่อ-repository/`

## ฟังก์ชัน

- ปุ่มเปิดต้นทาง Google Sheets, Canva, Google Drive ครบทั้ง 6 ลิงก์
- ปุ่มคัดลอกลิงก์แต่ละรายการ
- เช็กลิสต์และความคืบหน้า 0–6 รายการ (บันทึกเฉพาะอุปกรณ์/เบราว์เซอร์ด้วย localStorage และแยกตามวันเวลาไทย)
- ปุ่มล้างเครื่องหมายของวันปัจจุบัน
- คำเตือนว่าข้อมูลตั้งจุด ว.43 ต้องตรงกับรายงาน 191

## ข้อจำกัดและความปลอดภัย

เว็บเป็นเพียงลิงก์ฮับ **ไม่ได้อ่าน เขียน หรือส่งข้อมูลเข้าระบบต้นทาง** การติ๊กถูกไม่ยืนยันว่ารายงานถูกส่งจริง ผู้ใช้งานต้องมีสิทธิ์เข้าถึงเอกสาร Google/Canva/Drive จากเจ้าของไฟล์อยู่แล้ว อย่านำรหัสผ่าน โทเค็น หรือข้อมูลลับมาใส่ในเว็บสาธารณะ

เปิดบน GitHub Pages ได้โดยไม่ต้องใช้โครงสร้าง build หรือเซิร์ฟเวอร์
